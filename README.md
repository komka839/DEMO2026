# DEMO2026
Пояснительная записка для сдачи экзамена

Сначала заходим на 192.168.2.202:3000, кликаем обзор сверху и пишем в поиске Demo, жмём найти. По своему варианту ищем материалы (Кстати Part2 это Вариант 1, а Part1 это Вариант 2) и скачиваем их, потом устанавливаем виртуалку. Примерные файлы модуля 1-3 вы можете найти [здесь](https://github.com/komka839/DEMO2026/tree/main/%D0%9C%D0%BE%D0%B4%D1%83%D0%BB%D1%8C%201-3)
Каждый файл нужно отредактировать под свой вариант, у некоторых надо поменять названия базы данных, у некоторых количество создаваемых баз данных, так что полностью их копировать не надо!!

После редактирования скриптов запускаем их через cmd командой

psql -U sa -d postgres -f название_скрипта.sql

Вводим пароль и скрипт должен выдать результат. Так же не знаю почему, но на некоторых компах скрипты запускаются с ошибкой синтаксиса, а на некоторых нормально. Советую садиться за комп у окна, т.к. там сидел я и ничего такого не происходило.
